Muse Gadget フラッシャー

M5StickS3 に Muse Gadget ファームウェアを書き込み、初期設定を行います。Chrome または Edge（デスクトップ版）をご利用ください。

公式イメージとの主な違い

公式の muse-gadget-sdk をベースに、M5StickS3 向けに以下の機能を追加・変更しています。

  • 日本語表示: 推奨の Noto Sans JP 16px を同梱し、JIS X 0208 および環境依存文字（①②③など）に対応。GNU Unifont 版も選択可能。
  • テキスト主体の画面: アバターを非表示にし、返答テキストを省略せず自動スクロールで表示。
  • Wi-Fi 複数登録: 最大8件を保存し、本体メニューから切り替え可能。Web フラッシャーから読み込み・編集・個別削除にも対応。
  • 絵文字表示: Noto Emoji 16px モノクロに対応。単一コードポイントを表示（ZWJ 結合・肌色・国旗は非対応）。
  • 最新メッセージ表示: マイク（前面）ボタンのダブルクリックで、最新の Muse メッセージを取得・表示。
  • セキュリティ配慮: Wi-Fi パスワードはブラウザに保存せず、SDK トークン保存はオプトイン。CSP とシリアル改行インジェクション対策を適用。
  • 書き込みと設定: Web Serial でファームウェアを書き込み、SDK トークンと Wi-Fi 設定を USB 経由で本体に直接保存。

対応機能: ファームウェア書き込み / SDK トークン設定 / Wi-Fi の登録・読込・編集・削除 / 接続テスト / 本体メニューでの Wi-Fi 切替 / 最新メッセージ表示 / 絵文字表示

1. 接続と準備

  1. USB データ通信対応ケーブルで M5StickS3 を PC に接続します。
  2. 初回書き込み時: 本体の側面ボタンを長押しし、内部の緑色 LED が点滅したら準備完了（ダウンロードモード）です。
  3. ファームウェア更新時: すでに Muse が動作している場合は、ボタンを押さずにそのまま接続してください。

2. ファームウェアの書き込み

本ツールで書き込むファームウェアは、公式の muse-gadget-sdk をベースに、日本語フォント（Noto Sans JP）の最適化、絵文字（Noto Emoji）のモノクロ表示、マイクボタンのダブルクリックで最新の Muse メッセージを表示、Wi-Fi 複数登録・本体メニュー切替機能、アバターを非表示にしたテキスト主体の画面（返答は省略せず自動スクロール）、①②③ などの環境依存文字への対応 を追加した M5StickS3 向けのカスタムビルドです。現在のビルド: RH0.07 - 20261105。

このブラウザは Web Serial に対応していません。Chrome または Edge（デスクトップ版）をご利用ください。 Web Serial は HTTPS または localhost 環境でのみ動作します。

書き込み中はブラウザのタブを最前面のままにしてください。完了後、画面が暗い場合は側面ボタンを1回押して起動してください。

3. SDK トークン

Muse とペアリングするためのトークンです。gadgets.muse.ai で取得できます。ファームウェア書き込み後、USB 経由で本体の不揮発性メモリ（NVS）へ安全に転送されます。

4. Wi-Fi 設定（最大 8 件）

本体に登録する Wi-Fi ネットワーク（2.4 GHz 帯のみ）を入力してください。複数（最大 8 件）登録でき、本体メニューからの切り替えや複数環境での自動接続が可能です。※ パスワードはブラウザのストレージに保存されず、メモリ上でのみ送信されます。SSID にカンマは使用できません。

【ご注意】 このフラッシャーで本体に Wi-Fi を登録した場合でも、Muse アプリでの初回ペアリング時には、アプリ側でも Wi-Fi 選択とパスワード入力が改めて必要になります（Muse の初期セットアップ仕様です）。

SSIDパスワード

検出されたネットワークをクリックすると SSID 欄に入力されます（パスワードは手動で入力してください）。

    5. 本体へ設定を送信

    入力した SDK トークンおよび Wi-Fi 設定を本体に保存します。既存のペアリング情報は保持されます。

    「本体から読み込む」で、本体に保存されている SSID とパスワードを一覧に読み込めます。読み込んだパスワードはブラウザのストレージには保存されません。読み込み後に削除した行は「Wi-Fi のみ送信」で本体からも削除されます。

    困ったとき（FAQ）
    • ポート一覧にデバイスが表示されない: 充電専用ケーブルではなく、データ通信対応ケーブルであることを確認してください。初回書き込み時は、側面ボタン長押しで内部の緑色 LED が点滅していることを確認してください。
    • 書き込みが失敗する: 一度 USB ケーブルを抜き、側面ボタン長押しで緑色 LED 点滅を確認してから再度接続してお試しください。
    • 書き込み後に画面が暗いまま: 側面ボタンを1回押して起動（リセット）してください。
    • Wi-Fi に接続できない: 2.4 GHz 帯（5 GHz 帯は非対応）およびパスワードを確認してください。本体の側面メニュー → Wi-Fi からも接続先を切り替えられます。
    • 工場出荷時のファームウェアに戻したい: M5Burner ツールから STICKS3 を選択して書き戻すことができます。
