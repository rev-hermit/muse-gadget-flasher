Muse Gadget フラッシャー

M5StickS3 に Muse Gadget ファームウェアを書き込み、初期設定を行います。Chrome または Edge（デスクトップ版）で開いてください。

1. 接続と準備

  1. USB データ対応ケーブルで M5StickS3 を PC に接続します。
  2. 初回書き込み時: 本体の側面ボタンを長押しし、内部の緑色 LED が点滅したらダウンロードモードに入っています。
  3. ファームウェア更新時: すでに Muse が動作している場合は、長押しせずそのまま接続してください。

2. ファームウェアの書き込み

本フラッシャーで書き込むファームウェアは、公式の muse-gadget-sdk をベースに、日本語フォント（Noto Sans JP）の最適化 および Wi-Fi 複数登録・本体メニュー切替機能 を追加した M5StickS3 向けのカスタムビルドです。

このブラウザは Web Serial に対応していません。Chrome または Edge（デスクトップ版）をご利用ください。 Web Serial は HTTPS または localhost 環境でのみ動作します。

書き込み中はブラウザのタブを最前面にしてください。完了後、画面が暗いままなら側面ボタンを1回押して起動してください。

3. SDK トークン

Muse とペアリングするためのトークンです。gadgets.muse.ai で取得できます。ファームウェア書き込み後、USB 経由で本体の NVS（不揮発性メモリ）へ安全に転送されます。

4. Wi-Fi 設定（最大 8 件）

本体に登録する Wi-Fi ネットワーク（2.4 GHz 帯のみ）を入力してください。複数（最大 8 件）登録しておくことで、本体メニューからの切り替えや複数環境での自動接続が可能になります。※ パスワードはブラウザのストレージには保存されず、メモリ上でのみ安全に送信されます。SSID にカンマは使用できません。

【ご注意】 このフラッシャーで本体に Wi-Fi を登録した場合でも、Muse アプリで初回ペアリングを行う際には、アプリ側でも Wi-Fi の選択とパスワード入力が改めて必要になります（Muse の初期セットアップ仕様です）。

SSIDパスワード

見つかった AP をクリックすると SSID 欄に入力されます（パスワードは別途入力してください）。

    5. 本体へ設定を送信

    入力した SDK トークンおよび Wi-Fi 設定を本体に書き込みます。既存のペアリング情報は保持されます。

    困ったとき（FAQ）
    • ポート一覧にデバイスが出ない: 充電専用ケーブルではなくデータ通信対応ケーブルか確認してください。初回は側面ボタン長押しで緑 LED が点滅しているか確認してください。
    • 書き込みが失敗する: 一度 USB ケーブルを抜き、側面ボタン長押し → 緑 LED 点滅を確認してから再度接続してお試しください。
    • 書き込み後に画面が暗いまま: 側面ボタンを1回押すと電源が入りリセット起動します。
    • Wi-Fi に接続できない: 2.4 GHz 帯（5 GHz 帯は非対応）およびパスワードを確認してください。本体の側面メニュー → Wi-Fi からも接続先を切り替えられます。
    • M5Stack の元ファームに戻したい: M5Burner ツールから STICKS3 を選択して書き戻すことができます。
